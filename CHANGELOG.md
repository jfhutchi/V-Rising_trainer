# Changelog

## 0.6.5 - 2026-09-27

- Default the read-only achievement checklist to the signed-in Steam account, instead of a personal account ID.
- Preserve explicit Steam profile overrides. Report missing account detection without querying an unrelated profile.
- Add a version-checked release packager that verifies every ZIP entry against its source file and writes a SHA-256 checksum.
- Include public installation documentation, a Nexus listing draft, full trainer source and upstream item-catalog license attribution.
- Preserve the existing combat, blood, item, building, travel and servant controls from 0.6.4.

## 0.6.4

- Initial repository import of the private-world trainer, helper installers and read-only Steam achievement checklist.
